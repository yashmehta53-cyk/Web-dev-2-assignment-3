# 🎓 Student Scoreboard (React)

A simple React app to manage student scores, check pass/fail status, and calculate basic statistics.

---

## 🚀 Features

- Add new students with scores  
- Update student scores  
- Automatic **PASS / FAIL** status  
- Shows:
  - Total students  
  - Passed students  
  - Average score  
- Clean dark UI (futuristic style)

---

## 🛠️ Tech Used

- React (useState)
- Basic CSS
- No external libraries (beginner-friendly)

## ▶️ How to Run

1. Open terminal in project folder

2. Install dependencies:
` npm install `

3. Start the app:
` npm run dev `

---

## ➕ How to Use

- Enter **student name** and **score**
- Click **+ ADD**
- Update scores using input field and click **SAVE**
- PASS if score ≥ 40  
- FAIL if score < 40
